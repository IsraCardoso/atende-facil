# Convencao de Commits

## Tipos

- `feat`: nova funcionalidade
- `fix`: correcao de bug
- `refactor`: melhoria sem mudar comportamento
- `test`: testes
- `chore`: infra/config
- `docs`: documentacao

## Formato

`tipo: descricao curta`

## Exemplos

- `feat: adiciona container de DI`
- `fix: corrige validacao de env`
- `refactor: simplifica flow engine`
- `test: adiciona testes de session`
- `chore: configura biome`

## Regras

- mensagens claras
- sem "update" ou "fix stuff"
- foco em uma responsabilidade por commit
